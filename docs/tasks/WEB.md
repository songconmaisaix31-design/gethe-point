# Web Task Card

## Goal

Turn the approved static Style A prototype into a responsive role-based Web experience for the exact Demo path.

## Write Paths

- `src/app/(ui)/**`, `src/app/page.tsx`, `src/app/layout.tsx`, `src/app/globals.css`
- `src/components/**`
- `public/**`

## Acceptance

1. Primary home is a responsibility map, partner home shows owned/pending handovers, and subject home is a large-type chat surface.
2. Blocked handover, consent choices, burden-count change, care escalation, and notification truth labels are visibly demonstrable.
3. Style A tokens are preserved; no screenshot is used as the final UI.
4. Subject text is at least 20px, targets at least 60px, contrast is strong, reduced motion works, and desktop/mobile do not overflow.
5. Focused checks pass; only assigned paths change; worktree is clean and pushed.

## Explicitly Do Not

- Change contracts/domain/database, add a design system dependency, or claim live hardware/provider success.
